# Security Policy

## Supported versions

Security fixes are made on the current `develop` branch. Update to its latest
revision before reporting an issue.

## Reporting a vulnerability

Please do not report suspected vulnerabilities in public issues or discussions.
Use GitHub's private vulnerability reporting form for this repository:

<https://github.com/ahokinson/mitos/security/advisories/new>

Include the affected revision, a clear reproduction, the potential impact, and
any suggested mitigation. We will acknowledge reports within seven days and
coordinate disclosure after a fix is available.
